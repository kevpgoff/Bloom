# Credits for audio

Every audio file in `game/audio/` that was not made for the game is listed here, as `game/art/CREDITS.md` does for art. The game is sold, so each license must allow that.

`sfx/` needs no row: every file in it is made for the game. `tools/SfxGen` renders each one from a recipe in `tools/SfxGen/recipes/` or, for a ship's own set, in `tools/SfxGen/sets/`, and both are kept in the repo.

| Files | Author | Source | License |
| --- | --- | --- | --- |
| `music/` (every file; `tools/import-music.sh` builds them from the tracks listed in `tools/music-tracks.tsv`) | Voltz Supreme | ["Analog Ambience"](https://voltzsupreme.itch.io/analog-ambience) on itch.io, bought by the owner | Commercial and non-commercial use, with the credit "Music by Voltz Supreme". The game must show this credit to players. The license doesn't cover sharing the files, so they are not in the repo. The creator asked buyers not to edit the music. The owner decided on 2026-11-22 that trimming tracks is fine; only the two stings are cut, and every track is set to the same loudness |
